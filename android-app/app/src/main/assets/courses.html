课程大纲

14 个分类、体系化的 AI Agent 开发路径。每篇教程都是「能跑的骨架 + 详细注释」。

🐍

Python

核心语法 · FastAPI · 工程化

  • Python 核心与现代语法 类型注解/typing、虚拟环境与 pyproject、模块与包机制、函数进阶、生成器/异步、高频标准库——面向有经验开发者的 Python 核心要点与踩坑。
    入门 35 分钟
  • FastAPI 实战：路由、依赖注入、校验、异步与 OpenAPI 用 FastAPI 搭建类型安全、自带文档的异步 API，深入路由、Pydantic 校验、依赖注入、异步视图、中间件、OpenAPI 与安全。
    进阶 45 分钟
  • Python 工程化：测试、Lint、打包、日志与配置 用 pytest 写测试、ruff/mypy 统一质量门禁、打包发布、logging 与配置管理，构建可维护可交付的 Python 项目。
    进阶 40 分钟
  • asyncio 异步编程：事件循环、协程与并发原语 理解 asyncio 的事件循环与协程模型，掌握 async/await、Task 调度、并发原语（锁/队列/信号量），并学会和同步/CPU 密集库安全互操作，避开最常见的异步坑。
    进阶 40 分钟
  • pandas / numpy 数据处理实战 用 pandas 的 Series/DataFrame 与 numpy 向量化做高效数据清洗，覆盖向量化思维、缺失值处理，并说明它如何接入 LLM 数据管线。
    进阶 25 分钟

AI Agent

设计模式 · 多智能体 · 记忆

  • 什么是 Agent：定义、边界、架构与局限 厘清 Agent 与普通 Chatbot 的区别，界定 LLM 的能力边界，拆解典型架构，盘点应用场景与局限，并搭好能跑通的最小开发环境。
    入门 30 分钟
  • Agent 系统架构设计：模块划分、契约、状态机与可观测性 从一次性脚本进阶到可维护的 Agent 系统——感知/决策/执行/记忆四层划分、模块间接口契约、显式状态机驱动、可观测性内建，并给出生产级骨架与对比、踩坑。
    进阶 35 分钟
  • 架构模式：ReAct、Plan-and-Execute、Reflexion 从"会调工具"升级到"会思考"。掌握三种主流 Agent 架构模式的原理、适用场景、可运行骨架与取舍，避免一上来就堆代码。
    进阶 30 分钟
  • 记忆系统：短期/长期记忆与读写策略 理解 LLM 的无状态本质，掌握短期记忆（滑动窗口/摘要）、长期记忆（键值/向量/摘要）、三类记忆的读写策略与淘汰机制，并给出可运行骨架。RAG 整体已归独立分类，本篇只聚焦记忆。
    进阶 32 分钟
  • 多 Agent 协作：角色编排、通信与任务分解 当单 Agent 力不从心，用角色编排、任务分解与通信协议把多个 Agent 组织起来。掌握三种协作拓扑与可运行骨架。
    高级 34 分钟
  • Agent 主循环与控制流：事件驱动、上限、超时与中断 拆解 Agent 主循环的事件驱动模型，讲透步骤上限、超时/中断、并发执行与错误恢复的设计要点，给出带护栏的可运行骨架与常见坑。
    进阶 22 分钟
  • 规划与推理：ReAct、Plan-and-Execute、反思与思维树 拆解 Agent 的『思考策略』——ReAct 边想边做、Plan-and-Execute 先规划后执行、Reflexion 自我批评、ToT 思维树，讲清原理、与 LLM 推理的关系，并给出可运行骨架、对比与踩坑。
    进阶 38 分钟
  • 多模态 Agent：视觉/语音/文档理解与模态路由 构建能处理图像、语音、文档的 Agent——模态路由、VLM 视觉理解、ASR/TTS 语音管线、文档解析、与工具调用协同，给出典型端到端管线骨架、对比与踩坑。
    进阶 40 分钟
  • Agent 规格定义：需求拆解、能力清单与输入输出契约 写代码前先写规格。讲透如何把模糊需求拆成可执行项、列出能力清单、定义输入输出契约与评测口径，并给出用 Zod 固化契约的骨架。
    进阶 20 分钟
  • 实战：从零搭一个可运行的 Agent 项目 把 M0–M7 串成一条线——做一个会规划、检索、调用工具、记忆并产出带引用报告的「研究助手 Agent」。完整目录、可运行代码、扩展路线与工程化清单。
    高级 50 分钟
🧠

LLM大模型

Transformer · 微调 · 私有化部署

  • 主流模型选型：能力矩阵与决策树 横向对比 GPT/Claude/Llama/通义/文心/GLM 等主流大模型的能力边界、上下文、价格与部署形态，给出可运行的模型横评骨架与选型决策树，帮有经验的开发者在真实项目里选对模型。
    进阶 30 分钟
  • Transformer 原理：注意力、位置编码与 KV Cache 拆解自注意力数学、多头机制、绝对/相对位置编码、Decoder-only 架构与 KV Cache 的关系，给出可运行的自注意力计算骨架，并讲清这些原理如何决定推理延迟与显存，面向有经验的开发者。
    高级 40 分钟
  • 分词器：BPE/WordPiece、计费与跨语言 理解 LLM 如何把文本切成 token，掌握 BPE/WordPiece 原理、token 计费口径、中英跨语言差异与截断处理，并给出可运行的 token 计数骨架，面向有经验的开发者。
    进阶 18 分钟
  • 预训练基础：从语料到基座模型 讲清 LLM 预训练的三大支柱——数据、目标函数、规模定律，并用因果语言建模把训练闭环讲透，最后厘清预训练与微调的边界，给你能落地的概念骨架。
    进阶 25 分钟
  • 微调实战：SFT 与 LoRA 从数据到上线 从『要不要微调』的决策出发，讲透 SFT 数据格式与 Zod 校验、全参/LoRA/QLoRA/PEFT 方案对比、OpenAI 托管微调可运行骨架、LoRA 训练伪代码、评估与成本，给有经验开发者能落地的全流程。
    高级 45 分钟
  • 推理部署与量化：把模型跑起来还跑得稳 从推理服务架构与 KV Cache 讲起，对比 vLLM/TGI/Ollama/llama.cpp 与云 API，拆解 INT4/8 量化与连续批处理原理，给出 OpenAI 兼容本地部署可运行骨架与量化伪代码，并点出上线踩坑。
    高级 45 分钟
  • Embedding 模型：把文本变成可计算向量 讲清 Embedding 的数学原理、主流模型选型、维度与归一化、领域适配/重训思路，以及它如何成为 RAG 检索的基石。给出 OpenAI embeddings 与相似度计算的可运行骨架。
    进阶 22 分钟
  • 函数调用机制：模型如何『调用工具』 从 LLM 视角拆解 Function Calling——训练机制、工具 schema 约束、并行调用、参数纠错与自纠正闭环，以及它如何驱动 Agent。给出含 Zod 校验的可运行骨架，并对比 JSON 模式/微调/提示工程。
    高级 38 分钟
  • 长上下文：窗口、缓存与压缩 讲清上下文窗口的本质、RoPE 位置编码扩展（NTK/插值/YaRN 思路）、Prompt 缓存省成本、以及长文档的压缩与摘要策略。给出 map-reduce 摘要的可运行骨架与踩坑清单。
    进阶 24 分钟
✍️

Prompt工程

框架 · 项目踩坑与优化

  • 基础技巧：零样本/少样本与清晰指令 掌握提示工程最底层的四项基本功——零样本与少样本、指令清晰化、分隔符隔离、输出格式约束，并给出可运行骨架与高频踩坑。
    入门 18 分钟
  • 角色与系统提示：让模型进入正确语境 理解 system 消息的定位与生命周期，掌握系统提示设计、角色设定的边界约束与优先级策略，并给出可运行骨架与生产踩坑。
    入门 16 分钟
  • 思维链 CoT：让模型把推理写出来 系统讲解思维链（Chain-of-Thought）的三种形态——Zero-shot / Few-shot / Auto-CoT，剖析其生效原理与适用边界，对比直接作答与更复杂推理范式，并给出可运行骨架、工程踩坑与评测口径。
    进阶 28 分钟
  • 提示链与结构化输出：把任务拆成可调试的流水线 掌握提示链（Prompt Chaining）思想——将复杂任务函数式拆解为多步、用 JSON 约束在步骤间传递数据、用 Zod 校验与调试钩子保证可观测，并给出可运行骨架、与设计单条巨提示的对比及踩坑。
    进阶 30 分钟
  • 高级推理技巧：自我一致性、ToT 与 Reflexion 在思维链之上进阶——自我一致性（多链投票）、思维树（分支搜索）、Reflexion（反思复盘）、元提示（让模型写提示），含原理、可运行骨架、对比与踩坑。
    高级 22 分钟
📚

RAG

检索增强生成全链路

  • RAG 总览：检索增强生成的端到端逻辑 从为什么需要 RAG 入手，拆解从文档摄入到查询生成的端到端流水线，定位质量瓶颈，并给出与微调、长上下文的选型对比与可运行骨架。
    入门 35 分钟
  • 文档切分：把长文切成可检索的语义单元 系统讲解固定切分、递归切分、语义切分的原理与可运行实现，覆盖重叠窗口、表格与代码块的特殊处理，并对比选型与常见坑。
    进阶 35 分钟
  • 向量化：Embedding 模型选型与维度归一化 讲解 Embedding 如何把文本变成可检索向量，覆盖模型选型、维度与 Matryoshka 截断、归一化对相似度的影响，以及领域适配思路。
    入门 18 分钟
  • 向量数据库：RAG 的语义检索底座 理解向量数据库在 RAG 中的角色，掌握 ANN 与 HNSW 索引原理，对比 Milvus/Qdrant/PGVector/Chroma 的取舍，并给出可运行骨架与部署、踩坑要点。
    进阶 38 分钟
  • 混合检索：BM25 + 向量的优势互补 理解纯向量检索的盲区，掌握 BM25 关键词召回、向量语义召回、RRF 融合、元数据过滤与查询改写，给出可运行骨架与踩坑要点。
    进阶 36 分钟
  • 重排序：用 Cross-Encoder 精排检索结果 理解为什么粗排后还要重排，掌握 Bi-Encoder 与 Cross-Encoder 的差异、Top-K 召回-精排策略，并给出重排骨架与踩坑要点。
    进阶 22 分钟
  • RAG 生成与引用：把检索结果变成可信答案 聚焦 RAG 的『生成』阶段——上下文压缩、引用溯源、抗幻觉与答案组织，给出 OpenAI SDK + Zod 的可运行骨架，并对比朴素拼接的优劣与常见坑。
    进阶 22 分钟
  • GraphRAG：用知识图谱做全局问答 深入 GraphRAG 的原理——实体关系抽取、社区摘要、全局/局部查询模式，给出 LLM 抽取骨架与图谱构建思路（伪代码，以官方文档为准），并对比传统向量 RAG 的适用边界与踩坑。
    高级 38 分钟
  • Agentic RAG：会自己决定『查什么、查几次』的检索 把检索从『一次性取 top-k』升级为自主决策的 Agent 过程——检索 Agent、自省检索（Self-RAG）、查询路由，以及与多 Agent 协作的结合。给出 OpenAI SDK + Zod 可运行骨架与思路伪代码。
    高级 40 分钟
  • RAG 评估：检索/生成指标、Ragas、人工标注与回归测试 把 RAG 拆成检索与生成两段分别量化，讲清 Context Recall/Precision、Faithfulness、Answer Correctness 等核心指标的原理与可运行计算骨架，用 LLM-as-judge 与 Ragas 思路做自动评估，并落到人工标注与 CI 回归测试。评估框架以官方文档为准。
    高级 40 分钟
  • RAG 生产化：增量更新、缓存、监控与成本控制 把能跑通的 RAG 管线搬上生产：知识库增量更新策略、查询/embedding/答案三层缓存、质量与成本监控、以及可落地的成本控制手段。面向有经验开发者，重实战骨架与踩坑。
    进阶 25 分钟

    进阶 36 分钟
  • Agent 插件 / Skill 开发：契约、注册发现与上下文注入 讲清如何为 Agent 平台开发可复用的插件/Skill——统一的插件契约（manifest）、注册与自动发现机制、运行期上下文注入的三种方式，并给出与框架无关的骨架与对比、踩坑。
    进阶 22 分钟
